IMPORTANT COURSE DISTINCTION
- MotivationalSpeech.mp4 belongs to the Motion Graphics class and appears on
  motion-graphics.html only.
- Classic is the Art 74 time-based mashup. Its video is datacenter_resized.mp4,
  embedded on mashup.html; it is not part of the Glitch project.
- The provided datacenter_resized.mp4 lasts about 0.92 seconds. If this is a
  shortened export, you can replace assets/datacenter_resized.mp4 with a longer
  version under the same filename.
- The rose project has its own subfolder so its index.html does not overwrite
  the portfolio homepage. Its pages link back to the main site.

TO VIEW LOCALLY
1. Unzip the folder.
2. Open index.html in any web browser.
3. Test the navigation and media playback; do not move files out of their folders.

TO PUBLISH ON GITHUB PAGES
1. Use a repository named YOUR_GITHUB_USERNAME.github.io.
2. Upload all the items INSIDE this ZIP to the root of that repository (do NOT
   upload the ZIP itself and do NOT put the files under an extra parent folder).
3. Keep index.html in the repository root and preserve assets/ and rose/.
4. In repository Settings > Pages, choose Deploy from a branch, main, / (root).
5. Your site URL is https://YOUR_GITHUB_USERNAME.github.io/ after publishing.
6. Test the site online and submit that published link to Canvas.

NOTE: The site is NOT already published. The GitHub username/URL was not supplied.
The Art 74 mashup video is included. If you have a longer final export, replace
assets/datacenter_resized.mp4 or use an unlisted YouTube embed to reduce size.
